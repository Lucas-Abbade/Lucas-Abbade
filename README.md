## ⭐ Projetos em destaque

### 🎵 EasyCovers — Site de suporte para covers musicais
Plataforma web Full-Stack de processamento de áudio voltada para músicos e produtores.

- Permite a ingestão de faixas (via upload, YouTube ou Spotify) e realiza a separação em até **6 stems isolados** utilizando IA com **PyTorch** e **Demucs**.
- Back-end em **Python** (**FastAPI**, **SQLAlchemy**, **FFmpeg**) responsável pela normalização de áudio em **PCM 24-bit** e autenticação segura com **OTP**.
- Front-end em **React 19** (**Vite**, **Tailwind CSS**) com engine integrada em **Tone.js (Web Audio API)** para mixagem multipista em tempo real, controle de ganho, solo/mute e marcadores de treino.

**Tecnologias:** Python · FastAPI · SQLAlchemy · FFmpeg · PyTorch · Demucs · React 19 · Vite · Tailwind CSS · Tone.js (Web Audio API)  
**Repositório:** [github.com/Lucas-Abbade/easyCovers](https://github.com/Lucas-Abbade/easyCovers)
